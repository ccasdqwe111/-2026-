# 2026最新版本东郊到家带同城搭子系统源码

源码获取：ym7k.com/19143/ 

这套是二合一复合型同城源码，**上门技师预约服务模块 + 同城搭子组局模块整合在一套系统内**，Uniapp 前端 + ThinkPHP 后端，支持 H5、微信小程序，自带代理商、分销、虚拟号、语音通知，市面热门双业务同城 O2O 运营版源码，私有化部署，支持深度二开。

## ✅ 技术环境

- 前端：UniApp 开源前端，可打包小程序、H5 公众号
- 后端：ThinkPHP（PHP7.3+），MySQL5.6，Redis、Swoole 扩展
- 存储：阿里云 / 腾讯云 OSS
- 地图：高德 / 百度 LBS 定位、距离计算、导航
- 支付：微信支付、支付宝、余额支付、优惠券抵扣
- 配套：短信、语音通知、隐私虚拟中间号（保护双方手机号）

## ✅ 端口构成：用户端｜技师端｜代理商端｜总后台

### 一、【东郊到家上门服务模块（核心）】

1. 技师入驻审核：技师提交资料、证件上传、平台审核，可设置入驻保证金、服务范围、可接单区域
2. LBS 就近派单：地图展示附近技师，用户自选技师 / 平台智能派单，预约上门时间、填写上门地址
3. 服务项目管理：推拿、SPA、采耳、家政、美容等类目自定义，设置时长、单价、加钟套餐
4. 订单全流程：下单→支付→技师接单→出发打卡→服务打卡→完成、评价、退款售后
5. 安全机制：虚拟号通话（隐藏真实手机号）、服务轨迹、紧急报警、订单语音提醒、短信通知
6. 资金结算：平台抽佣、技师收益、技师提现审核、流水对账、分账记录
7. 会员营销：VIP 会员、储值卡、优惠券、卡券转赠、限时活动弹窗、开屏广告

### 二、【内置同城搭子组局模块（新增整合）】

就是前面那款同城搭子组局系统融合进来，一套系统两个业务入口：

1. 用户自主发布组局：骑行、美食、露营、桌游、探店、运动、观影等，设置时间、地点、人数、费用（AA / 自费 / 收费）
2. 报名审核：发起人审核报名人员，满员成团、超时自动取消
3. 搭子主页、兴趣标签筛选、距离筛选、搭子资料卡片
4. 活动评论、活动通知、成团提醒
5. 可单独开关搭子模块，不想做搭子可以后台直接关闭该功能

### 三、分销 & 代理商裂变体系（运营重点）

1. 区域代理：按城市开通代理商，代理商可管理本城市技师、查看本城订单，拿区域分成
2. 分销推广：生成推广海报、邀请码，邀请用户下单、技师入驻都产生佣金
3. 渠道商、业务员子账号，渠道订单溯源、渠道专属优惠券
4. 团队数据看板、佣金明细、佣金提现审核、手续费配置

### 四、总后台管理功能

- 用户管理、技师管理、代理商管理、账号封禁、资质审核
- 服务类目、搭子活动分类、广告公告、首页 DIY 菜单配置
- 订单管理、售后退款、投诉工单、敏感词过滤
- 资金管理：余额、提现、平台收益、导出财务报表
- 通知配置：短信、语音通知、模板消息、虚拟号密钥配置
- 数据统计：新增用户、订单量、成交金额、各城市营收、搭子活动数据

### 五、技师独立端能力

- 接单 / 拒单、订单列表、导航上门、打卡签到、服务上传照片
- 收益明细、提现申请、日程排班、消息通知、客户评价查看

## ✅ 变现渠道

1. 上门服务订单抽成（主营）
2. 搭子活动报名费抽佣
3. 技师入驻费、保证金
4. 代理商加盟费、城市代理授权
5. 会员储值、广告位招商
6. 源码搭建、二开定制服务
